# Refresh

A spaced-repetition flashcard web app built with Python and NiceGUI.

## Requirements

- Python 3.10 or newer (developed on Python 3.12, Windows 11)

## Live App

https://refresh-zwch.onrender.com/

The free host puts the app to sleep when idle, so the first load can take 30 to 60 seconds.

## Run

```
pip install -r requirements.txt
python main.py
```

Then open http://localhost:8080 in a browser.
