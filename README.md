# Refresh

A spaced-repetition flashcard web app built with Python and NiceGUI. 

## Project Description

Refresh is a flashcard application designed to help students study and remember information. 
Users can create their own decks, add flashcards, and review them in a simple interface.
The goal is to make studying more organized and help users remember information over time.

## Installation Instructions

- Install Python 3.10 or newer.
- Download or clone the Refresh repository from GitHub.
- Open the project folder in a terminal.
- Install the required packages using the command below.

```
pip install -r requirements.txt
```

## Run Instructions

After completing the installation steps, follow these instructions to run Refresh locally.

1. Open a terminal in the Refresh project folder.
2. Start the application using the following command:

```
python main.py
```
3. Open your web browser and go to http://localhost:8080.
4. The Refresh interface should now appear.
    
## Build Instructions

Refresh is built using Python, so no separate compilation is required. 
Once Python and the required packages are installed, the application is ready to run.
